Privacy policy

rclone backup client · effective 18 October 2026

This application is a personal-use Google OAuth client operated by Zach Scheffler ("the owner"). It is used only by the owner, through the open-source tool rclone, to copy files between the owner's own computer and the owner's own Google Drive accounts. This policy explains what data that involves.

What Google data the application accesses

With the signed-in user's consent, the application requests the Google Drive scope (https://www.googleapis.com/auth/drive) so that rclone can list, read, upload, update and delete files in that user's Google Drive. The only users are the owner's own Google accounts; the only Drive data touched is the owner's own.

How the data is used

Exclusively to back up, mirror and restore the owner's files between the owner's computer and Google Drive. Nothing is used for advertising, profiling, analytics, training, or any other purpose.

Where data is stored

There is no server. Files move directly between the owner's computer and Google's servers. The OAuth tokens that Google issues are stored only in rclone's configuration file on the owner's computer, protected by the operating system's file permissions. No copy of any file, token or account information is kept anywhere else by this application.

Sharing with third parties

None. No data obtained through Google APIs is sold, shared, transferred or disclosed to anyone, with the sole exception of transmission to Google itself as part of using the Drive API.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

Tokens remain on the owner's computer until revoked. Access can be revoked at any time at myaccount.google.com/permissions, after which the stored token stops working and can be deleted from rclone's configuration.

Changes and contact

Any change to this policy will be published on this page. Questions: zachscheffler@gmail.com.
