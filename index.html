rclone backup client

A personal-use Google OAuth application

This application is the OAuth client that rclone, an open-source command-line file-sync tool, uses to copy files between Zach Scheffler's own computer and his own Google Drive accounts. It exists so that rclone can authenticate with Google using its own client identity, as Google requires, instead of a shared one.

Who uses it

Only the owner of this application, with his own Google accounts. It is not offered to the public, has no sign-up, and provides no service to anyone else.

What it does

Purpose
Back up and mirror the owner's files to the owner's Google Drive, and restore them.
Runs on
The owner's computer only. There is no server component.
Data flow
Files travel directly between the owner's computer and Google Drive over Google's API.
